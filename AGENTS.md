# Grabby — notes for agents

- Package manager is **bun** (`bun.lock`). Add Expo-aligned packages with `npx expo install`.
- Before finishing: `bun run typecheck && bun run lint && bun run test` (and `bun run theme:check`).
- UI follows the Grabby design system: build screens only from `src/components/ui`, use theme
  tokens (`theme.colors.*`, `theme.space[n]`, `theme.type.*`), never raw colours or sizes.
  Copy is English, sentence case, verb first, no exclamation marks; versions exactly as posted.
- `src/theme/tokens.ts` is generated from `design/tokens.json` — run `bun run theme`, don't edit it.
- Schema changes: edit `src/db/schema.ts`, then `bun run db:generate` (commit `drizzle/`).
- The 4PDA parser (`src/fourpda/`) must keep working on its fixtures; when markup changes,
  add a fixture modelled on the real page and a test. Be gentle with the site.
- Native code lives in `modules/grabby-native` (Kotlin, classic Expo Modules DSL). JS reaches it
  only through `src/native`, which tolerates the module being absent.
- `android/` is generated by prebuild and git-ignored.
